Read-only review of the initial shared-core, academy and community migrations. Findings were sent to the integrator before hosted application. No tests or shared-file edits were performed during this review pass.

Mission-critical gaps noted in the initial source: transfers were request-only without approval/atomic execution; guardian grants were whole-family without per-child restrictions; assigned-coach emergency-contact projection was absent. These are scope gaps, not claims about the integrator's later revisions.

The review is complete for this source snapshot. Root is implementing fixes and regression tests; this document does not mark those changes independently verified. A later scoped review should reference the exact updated diff and test evidence.

## Compensation settlement extension review

Reviewed `20260920012833_product_compensation_settlements.sql`, the shared command dispatcher, immutable compensation contracts, request validators and payment UI on 2026-09-20. No exploitable authorization, double-settlement or reversal flaw was found in this source pass. Both financial capabilities are rechecked against the accrual's branch; Coach/Sales are excluded. The shared transaction advisory lock and accrual row lock serialize balance checks. A settlement records the exact approved amount only for still-eligible delivered sessions; a unique compensating reversal preserves history and releases the unpaid balance. The shared idempotency cache retains same-request safety and current access revision checks. This is offline accounting evidence, not a money transfer.

One UI inconsistency was corrected under integrator authorization: review/payment choices now filter each accrual or settlement by its branch-specific capability, and settlement/reversal choices require both matching financial capabilities. Previously, disjoint grants could display a choice that SQL correctly rejected. Scoped lint and TypeScript checks pass; transaction review is source-based, with the integrator's separate 18-assertion SQL settlement suite as prior evidence.
