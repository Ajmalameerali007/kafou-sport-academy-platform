# KAFOU public experience

Approved scope: cinematic cohesive home, four sports, broader programs, journey, concepts, locations, progressive trial, unified auth and safe role placeholders. Fresh Sites React/TypeScript starter. Integration-ready only, no backend claims, no operational dashboards.

## Execution ledger

- Environment: empty Git repository confirmed; new implementation explicitly authorized.
- Branch: codex/kafou-public. No prior architecture to preserve.
- Ruling: use native implementation in the selected empty checkout, with asset-only research and final independent review. Avoid unnecessary worktree for an unborn repository.
- Scaffold installed. Site registration started once. Supplied alpha PNG retained as source hero.
- Motion source inspected: ScrollTextMotion, RotatingOnScrollAnimations, StickySections, SlideshowAnimations demo1/slideshow, OnScrollPathAnimations, OneElementScroll, ScrollBasedLayoutAnimations, Lenis. Adapt techniques; no demo imagery or source bundles.
- Source boundaries: typed services return unavailable until a provider is implemented. Confirmed locations initially empty.
- First browser pass exposed a hydration race: native form submission could occur before React attached handlers. Fixed by rendering fields disabled until hydration; no pre-hydration personal data can enter a URL.
- Tablet QA found overflow in the four-item sport index; corrected its spacing and navigation breakpoint.

- Production QA found an upstream Vinext client-link prefetch/router undefined-function exception. Replaced cross-page navigation with native anchors and kept auth views in local History state; server rendering and the Sites stack are preserved.
- Independent motion review found stale inert state after scrub completion and scroll-position loss during responsive teardown. Timeline updates plus refresh synchronization fix scene accessibility; scoped matchMedia lifecycle capture restores the current section after rebuilding.
- Final accessibility pass increased small metadata sizes, darkened secondary text and corrected the 320px sport index/hero footer layout.
